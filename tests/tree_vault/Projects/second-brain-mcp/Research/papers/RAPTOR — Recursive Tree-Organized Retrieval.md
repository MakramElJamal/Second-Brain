# RAPTOR — Recursive Tree-Organized Retrieval

## Relevance to Second Brain MCP
Recursively cluster chunks, write a summary for each cluster, and repeat until a
tree of summaries is built. Broad questions are answered from high-level summary
nodes; detailed questions from the leaf chunks. Querying the collapsed tree, where
every node competes in one pool, worked better than walking it top-down.
